# Windows Node Feature Gap List

Compared repositories:

- **External reference repo:** `E:\Projects\openclaw-windows-node\src`
- **Current repo surface:** `apps/windows`

This document lists features that are implemented in the external Windows node repo but do **not** appear to be implemented in the current OpenClaw Windows companion app.

## Summary

The current `apps/windows` app already covers the operator shell basics: tray app behavior, gateway lifecycle controls, chat, sessions, approvals, pairing, Canvas/A2UI embedding, logs/diagnostics, device smoke tools, global hotkey support, and appearance customization.

The external repo goes significantly further in four areas:

1. **Native Windows node capabilities** — richer media, browser proxying, and TTS.
2. **Security/policy tooling** — URL risk evaluation and persistent exec approval rules.
3. **Desktop integration** — deep links, SSH tunnel management, command palette integration, and localized UX.
4. **Operational UX** — richer notification, activity, and structured diagnostics surfaces.

## Notes

- I intentionally excluded features that already exist in both repos, such as tray behavior, single-instance app lifetime, gateway connection basics, chat/session views, approvals, pairing, Canvas/A2UI rendering, logs pages, and appearance theming.
- I also excluded speculative gaps that were not clearly implemented in code on one side or clearly absent on the other.
- The largest roadmap deltas are **Windows node/media capabilities**, **network/security administration**, and **richer desktop-native UX surfaces**.
